# M04 — HPG H145 profile

## Goal

Replace the user's AAO-based H145 Stream Deck XL profile with one built on this plugin — same functional coverage, no external app.

## Inputs

- `docs/research/h145-aao-analysis.md` — patterns and counts.
- Local reference (not in repo): `~/Downloads/H145_2_0_vsL6a/H145.streamDeckProfile` (AAO, ~200 actions on 10 pages) and `H145_AxisAndOhsScripts.xml`.
- HPG H145 User Guide, L:Vars / H:Events chapters.

## Scope

- **SDK toggle pattern** in `var-toggle`: state from `L:H145_SDK_<X>`, press fires `H:H145_SDK_<X>_ON` or `_OFF` depending on state. Ideally expressible as plain settings (state var + on-action + off-action), not a hard-coded H145 action.
- MFD softkeys / knobs as `command` buttons with H:-events.
- Replacements for AAO `S:` script variables (page/mode state) — plugin-side state; port `macro` / `display-selector` from xp_streamdeck only if needed.
- Icons: catalog rows for the H145 buttons (`make icons`).
- Profile: build it on the Mac, export as `profiles/H145.streamDeckProfile` (own work — may be committed).
- Optional: a converter script AAO profile → this plugin (like xp_streamdeck's `convert-pilotsdeck.ts`) if it saves more time than manual rebuilding. Decide after a 10-action manual sample.

## Acceptance criteria

- [ ] Every action of the AAO profile has an equivalent, or is listed in the PR as deliberately dropped (with reason).
- [ ] Engine start, lights, AP modes/beeps, MFD softkeys tested in a real flight on the sim PC with the XL.
- [ ] State images follow the sim (switching in the virtual cockpit updates the button).
- [ ] `make check` green.
