One rule per line: condition | style | text, first match wins. Condition = RPN, true when non-zero, e.g. (L:X) 2 ==, (L:A) 1 == (A:SIM ON GROUND, Bool) 0 == and; * = always. Style: off white green amber red blue cyan. Text optional (empty = default text); \n = new line, {rpn} / {rpn|%.1f} = live value. # = comment.
